테스트 리그 사용 안내

  1. 구조와 스프링을 선택하세요.

    댐퍼의 압축·리바운드 감쇠를 각각 조절할 수 있습니다. 차체 질량과 타이어 설정은 고급 옵션에서 바꿉니다. 구조 변경에 따라 링크의 배치와 기하가 바뀝니다.

  2. 노면과 속도를 설정하세요.

    범프, 턱, 포트홀, 연속 요철을 선택한 후 시험을 시작하세요. 요철 1회 버튼으로 한 번의 충격 이후 복원 응답을 관찰할 수 있습니다.

  3. 그래프에서 시점과 구간을 살펴보세요.

    포인터를 올리면 해당 시점의 값을 확인합니다. 범례를 눌러 계열을 표시하거나 숨기고, 휠로 시간축을 확대하거나 드래그로 이동하세요. 실시간 추적을 켜면 최신 데이터를 따라갑니다. 현재 구간 버튼으로 최신 구간에 복귀합니다.

  4. 반응을 기록하고 비교하세요.

    변위·접지력·가속도 그래프와 구간별 분석값을 확인한 후 A/B에 기록하세요. 시험 데이터는 CSV로, 설정은 JSON으로 저장할 수 있습니다.

프로젝트 · 실험 기록 · 내보내기

실험 기록에서는 이름과 시험 시간을 지정해 같은 시작 상태로 응답을 남깁니다. 감쇠 스윕은 값을 바꿔 가며 시험을 차례로 기록합니다. 목록에서 실험을 선택하면 시간축을 맞춰 비교할 수 있습니다.

프로젝트 저장은 설정과 실험 기록을 JSON 파일로 보관합니다. 브라우저의 로컬 저장 상태와 파일로 내보낸 상태는 구분됩니다. 다른 장치에서는 저장한 프로젝트 파일을 열어 이어갈 수 있습니다.

PNG 캡처는 현재 3D 화면을 이미지로 저장합니다. 3D 모델은 화면의 시각화 형상을 GLB로 내보내며, 정밀 CAD나 동역학 해석 모델을 포함하지 않습니다. 시험 보고서와 CSV는 비교 결과를 공유할 때 사용합니다.

모델의 적용 범위 · 검증

스프링·댐퍼·타이어의 수직 응답을 계산하는 ¼ 차량 축약모델입니다. 고정 홀더에서는 차체를 고정하고 휠 응답을 계산합니다. 자동 모션 비율은 링크의 정적 자세에서 구하며, 그 제곱을 강성·감쇠에 적용합니다. 실제 부품 특성표를 입력하면 해당 곡선을 사용합니다. 링크·캠버는 대표 기하의 시각화이며 실제 CAD, 하드포인트·정밀 기구학, 3차원 강체 동역학과 부품 강도·피로 해석은 현재 포함하지 않습니다. 에어 스프링은 단순화한 압력·용적 모델을 사용합니다. 실측 검증 영역에서 데이터 출처와 조건을 기록하고 실차 응답을 비교하세요. 모델 기준 시험의 통과는 차량별 실측 검증을 대신하지 않습니다.
