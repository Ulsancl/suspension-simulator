Suspension Lab 1.3.0 · Windows 체험·실험 앱

1. Suspension-Lab-Setup-1.3.0.exe를 실행합니다.
2. 설치 위치를 선택하고 설치를 마칩니다.
3. 바탕화면 또는 시작 메뉴의 Suspension Lab 아이콘으로 실행합니다.

Node.js 설치, 별도 서버 실행, 인터넷 연결 없이 사용할 수 있습니다.

처음에는 ‘감쇠가 클수록 항상 좋을까요?’의 A/B 예시 실험을 실행해 보세요.
현재 설정을 유지하면서 같은 범프·30 km/h·8초 시험으로 예시 기록 두 개를 만듭니다.
리바운드 감쇠만 900과 4,200 N·s/m로 바꾸고 실제 RMS·정착·접지 결과를 비교합니다.
정착을 확인하지 못한 기록은 그 사실을 표시합니다. 두 기록 그래프 보기로 비교할 수 있습니다.

시험 시작/정지: 상단 시험 시작 버튼 또는 Space
초기화: R
프로젝트 열기: Ctrl+O
프로젝트 파일 저장: Ctrl+S
전체 화면: F11 (3D 화면만 확대: F)

설정과 보관한 실험 기록은 같은 Windows 사용자 계정의 앱 저장소에
자동 저장됩니다. 실시간 재생 이력은 종료 전에 실험 기록으로 보관하세요.
프로젝트 저장 버튼은 설정과 보관 기록을 JSON 파일로 백업합니다.
원본 실측 CSV는 프로젝트에 포함되지 않으므로 별도로 보관하세요.
웹 버전의 기록은 프로젝트 JSON으로 내보낸 후 이 앱에서 열 수 있습니다.
지원되는 이전 모델 기록은 원래 샘플·지표를 유지한 읽기 전용 기록으로 엽니다.
이전 결과를 현재 모델로 다시 계산하지 않으며 새 시험은 새 기록으로 만듭니다.
이전 저장 원문 보관 패널의 원문 내려받기로 원본을 따로 저장할 수 있습니다.
메모리 보관 또는 저장 실패 안내가 나오면 종료 전에 프로젝트 파일을 저장하세요.
자세한 보관·복구 방법은 resources/docs/storage-recovery.md에 있습니다.

저장 폴더: 도움말 > 저장 폴더 열기
기본 위치: %APPDATA%\Suspension Lab
앱 업데이트와 일반 제거 시 이 저장 폴더는 유지됩니다.
프로그램 제거: Windows 설정 > 앱 > 설치된 앱 > Suspension Lab > 제거

라이브 재생은 창을 최소화하면 잠시 멈춥니다.
시험 계산이나 파일 저장 중에는 완료될 때까지 기다린 후 종료하세요.

현재 모델은 수직 단일 휠의 축약 해석 모델입니다.
모델의 범위와 부품·실측 데이터 입력법은 설치 폴더 resources\docs에 있습니다.
표시 링크와 GLB는 대표 형상이며 실제 차량의 설계·정비·안전 승인을 제공하지 않습니다.
일반 체험용 검증 범위는 resources/docs/consumer-release.md에서 확인합니다.
이 설치본은 코드 서명 인증서 없이 제작되었습니다.
