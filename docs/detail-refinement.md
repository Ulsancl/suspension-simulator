# Suspension Lab 상세 관찰 개선

이 문서는 공개된 1.3 버전에서 시작한 상세 개선 브랜치의 계산 범위입니다. 문서의 존재가 새 설치 파일의 공개를 뜻하지는 않습니다. 기존 `quarter-car-1.3` 계산기와 실험 기록 형식을 유지합니다.

## 무엇을 읽을 수 있는가

현재 휠과 차체에 작용하는 부호 있는 힘을 각 질량×가속도와 대조합니다. 서스펜션 전달하중은 차체와 휠에 서로 반대 방향으로 작용하고, 중력은 아래쪽입니다. 고정 차체에서는 별도의 외부 구속력이 남는 힘을 상쇄합니다.

기존 `holderReaction`은 서스펜션 전달하중입니다. 새 상세값은 이 원래 값을 보존하면서, 차체의 고정 구속력 `ms g − Fsusp`를 별도로 구분합니다. 기본 정적 상태의 두 값은 각각 3138.128 N과 0 N입니다. 고정 차체는 움직이지 않으므로 구속력의 동력은 0입니다.

모션비가 만드는 축방향 변위·속도·힘도 함께 읽습니다. 이들은 한 시험 동안 일정한 모션비의 축약 모형 값입니다. 현재 화면 링크의 길이 변화를 그대로 스프링 압축량으로 해석하지 않습니다. 정적 휠 강성도 현재 비선형 접선 강성과 구분합니다.

## 손실·접촉·에어 해석

- 댐퍼의 순간 소산률은 실제 댐퍼 힘×상대 압축 속도입니다. 특성표로 계산한 힘이 있으면 해당 힘을 사용합니다.
- 스토퍼의 추가 감쇠는 범프·리바운드 한계를 더 누르는 방향에서만 작동합니다. 복귀할 때 되돌려주는 탄성 동력과 소산률을 구분합니다.
- 타이어는 기하학적 분리, 압축은 남았지만 인장을 막기 위해 힘을 0으로 제한한 상태, 실제 양의 접지력이 작용한 상태를 나눕니다. 제한 전 탄성·감쇠 시험 항과 실제 접지력을 혼용하지 않습니다.
- 에어 압력·체적은 기본 에어 법칙이 활성화된 경우에만 제공합니다. 스프링 특성표를 쓰면 에어 값은 적용하지 않습니다. 절대압력·게이지압력, 정적 초기 하중과 압력 증가분, 수치 보호 체적 하한을 명확히 구분합니다.

순간 운동에너지 변화율은 질량·속도·가속도로 구하고 현재 힘들의 동력 합과 대조합니다. 누적 에너지 원장, 실제 타이어 발열, 부품 온도·수명·공기 유량을 추가하지 않습니다. 장면의 링크·부싱·스프링 외형은 차량 전체의 다물체·강도·접촉 해석 결과가 아닙니다.

## 기록과 검증

상세 계산은 현재 스냅샷만 읽습니다. 시뮬레이션을 한 번 더 진행하거나 초기화하지 않고, 표시 속도를 물리 속도에 곱하지 않습니다. 기존 그래프 표본, 전체 시험 RMS·피크·접지 이탈 통계, 저장한 독립 시험과 CSV를 변경하지 않습니다. 현재 순간값과 선택한 그래프 구간 통계, 보관한 시험의 전체 통계를 구분해야 합니다.

12개 새 수치 검사는 모든 홀더·스프링·구조 조합의 힘수지, 적분된 운동에너지의 독립 중앙차분, 모션비의 일률 관계, 양쪽 스토퍼의 경계, 타이어 제한 분기, 에어 체적 하한, 특성표 우선순위와 외삽, 원본 불변성을 확인합니다. 화면 조작·실험 보관·설치 확인은 별도의 통합 검증 대상입니다.
