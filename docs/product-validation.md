# 제품 기능 검증 결과

> 이 문서는 이전 개발·배포 검증 기록입니다. 당시 요약과 수치는 역사 자료로 유지하며, 환경별 원본 QA 보고서·캡처는 공개 소스에서 제외했습니다. 현재 1.3.0 평가와 진행 상태는 [제품 평가 기록](consumer-release.md)을 확인하십시오.

최신 1.2.0 대시보드의 변경과 회귀 검사 결과는 [대시보드 검증](dashboard-validation.md)에 별도로 기록했다. 아래 자료는 1.1.0 검증 이력이다.

2026-10-01, **Suspension Lab 1.1.0 Engineering Preview / quarter-car-1.3**의 프로덕션 실행본을 Chromium과 Playwright로 검사했다. 제품 기능 20개, 기본 브라우저 회귀 16개, 디자인·분석 12개 항목이 모두 통과했으며 세 실행의 JavaScript·콘솔 오류는 0개였다. 별도로 완료한 수치·데이터 단위 검사 52개와 배포·오프라인 검사 6개를 합하면 검사 항목은 **106개**다. 이 수치는 구현 검사의 개수이며 실차 설계 인증이나 상용 지원 완료를 뜻하지 않는다.

기능 검증 주소는 `http://127.0.0.1:5174`였다. 기본 회귀 이후 변경한 비교 커서의 읽기값 초기화는 제품 검사에서 다시 확인했다. 마지막 번들은 빈 부품 그래프의 긴 안내문을 짧게 바꾼 것으로, 390×844 화면에서 실제 텍스트 경계가 SVG 안에 들어가는지 새 브라우저 문맥으로 확인했다. 가속도 선택 문구가 `가속도 (휠/차체)`이며 초고품질 옵션이 존재하는 것도 확인했다. 변경 범위가 다른 검사의 계산·흐름에 영향을 주지 않아 동일 기능 검사를 다시 반복하지 않았다.

## 확인한 제품 동작

- 네 작업공간의 선택 상태와 프리셋의 실제 물리 반영을 확인했다. 라이브 재생 위치가 다른 두 2초 표준 시험의 241개 샘플·누적 지표가 정확히 같았다.
- 기록·스윕 취소 시 부분 저장이 없고, IndexedDB 기록은 새로고침 후 유지된다. 프로젝트의 설정·기록·차량 이름·부품 표를 복원하며 불량 파일은 기존 상태를 보존한다.
- 최대 3개 실제 응답의 mm·m/s²·kN 단위, 조건 차이 안내, 최근 샘플 커서 값을 확인했다. 포인터 이탈·선택 교체 후 이전 값이 남지 않는다. 스윕의 실제 응답·순위·1% 접지 이탈 필터도 검증했다.
- CSV 샘플·선택 JSON 이력·HTML 보고서 통계가 저장 기록과 맞는다. 이름의 HTML·스크립트가 실행되지 않으며 보고서에 외부 자원이 없다.
- 부품 표가 정적 평형과 동적 힘에 적용되고, 대체된 슬라이더가 비활성화된다. 외삽 플래그도 저장·복원된다. 품질·스튜디오·기술·부품 집중 보기는 실제 렌더 설정·가시성·카메라 범위를 바꾼다.
- PNG 픽셀·GLB 바이너리와 전체 리그·SI 메타데이터를 확인했다. 1440×1000, 720×900, 390×844의 작업공간에 페이지 가로 넘침이 없고, 큰 그래프·줌·팬·구간 통계와 기본 재생·노면·A/B 기능이 동작한다.

## 측정 비교 회귀시험의 수치

실측 비교 UI는 **저장 기록에서 만든 합성 파일**로 검사했다. 이는 센서나 실제 차량에서 얻은 측정값이 아니다. 기록 시각에서 0.15초를 뺀 CSV에 사용자가 0.15초 오프셋을 지정해 정렬했고, 단위는 헤더에서 명시했다. 오프셋·진폭을 자동 피팅하지 않았다.

| 항목 | 결과 |
| --- | --- |
| 비교 샘플 | 192개 |
| 의도적으로 틀린 0.05초 오프셋의 가속도 RMSE | 3.71608 m/s² |
| 올바른 0.15초 오프셋의 가속도 RMSE | 5.23×10⁻¹⁷ m/s² |
| `travel_mm`를 m로 변환한 이동량 RMSE | 2.05×10⁻¹⁸ m |
| 새 접지력 SI 채널 파일 가져오기 | 통과 |
| 중복 시각의 불량 CSV 입력 후 이전 데이터·결과 보존 | 통과 |

이 결과는 파서·명시적 단위 변환·시간 정렬·선형 보간·잔차 계산이 일치한다는 근거다. 실제 차량에서 같은 오차가 나오거나 모델이 목표 차량을 설명한다는 근거로 사용할 수 없다.

## 물리·렌더링의 추가 증거

합성 부품 스프링 표의 정적 축하중은 **3,138.128 N**으로 320 kg의 차체 질량과 맞았고, 수동 모션비 1에서 유효 휠 강성은 **60,000 N/m**이었다. 범위 탐지 시험에는 댐퍼 속도 범위를 의도적으로 ±0.001 m/s로 좁혀 **93.01% 외삽**을 발생시켰다. 이 표는 플래그 회귀시험용이며 실제 부품 설계에 사용할 입력이 아니다.

스윕의 거친 혼합 노면에서는 세 후보 모두 접지 이탈이 1%를 넘었다. 결과는 자동 추천 없음으로 표시됐고, RMS가 더 낮다는 이유만으로 필터를 통과시키지 않았다.

| 압축 감쇠 (N·s/m) | 차체 RMS (m/s²) | 접지 이탈 (%) | 필터 통과 |
| --- | --- | --- | --- |
| 500 | 6.86336 | 35.70 | 아니오 |
| 2,500 | 4.48342 | 32.25 | 아니오 |
| 4,500 | 5.12394 | 24.50 | 아니오 |

데스크톱 고품질은 그림자 2,048·SSAO 16 샘플·MSAA 4를 사용했고, 초고품질은 4,096·32·4를 사용했다. 표준에서는 그림자와 SSAO가 꺼졌다. 이 검증 환경의 초고품질 픽셀 비율은 1.25였다. 모바일에서는 장치·화면 크기에 따라 효과와 해상도를 제한한다. 성능 수치는 GPU별 벤치마크로 검증하지 않았다.

PNG는 1,016×600이며 64×64 축소 샘플에서 1,513개 색상과 밝기 범위 229를 확인했다. GLB는 15,046,896 바이트·112메시였다. GLB 메타데이터에는 길이 m, 힘 N, 감쇠 N·s/m, 속도 km/h, 공기압 bar gauge를 명시하고, 정적 표시 자세·축소 동역학·대표 기하라는 범위를 포함했다.

## 전달본 확인

배포 ZIP을 작업 폴더 안에서 압축 해제하고 포함된 Node.js 실행 도구로 5176 포트에서 검사했다. 원본 `dist/`의 정적 파일 10개와 실행 도구의 SHA-256이 압축 해제본과 일치했다. 이 실행본에서도 6개 배포·오프라인 검사가 통과했고, 오프라인 비교 커서 이탈 시 이전 값 제거와 390px 빈 특성표 안내문 경계를 추가 확인했다. 전달본에는 앱, 실행 도구, 문서, 이 문서가 참조하는 검증 JSON·화면 자료와 Three.js MIT 고지가 들어 있다. 실제 브라우저의 설치 확인 대화상자는 자동화하지 않았다.
