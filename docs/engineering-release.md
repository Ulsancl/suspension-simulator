# 실제 차량 적용과 출시 조건

현재 전달 대상은 **1.2.0 Engineering Preview**입니다. 조건 관리, 기록, 부품 곡선 입력과 실측 잔차 계산을 제공하지만, 특정 차량에 대한 모델 타당성 검증과 상용 지원 조건은 아직 확정되지 않았습니다. 사용자 차량의 하드포인트·성능 곡선·동일 조건 실측 데이터는 제공되지 않았습니다.

## 적용 영역

현재 계산은 수직 단일 휠, 고정 홀더 또는 차체 질량의 2자유도 축소 모델입니다. 코일·점진형·단순 에어, 속도별 감쇠, 타이어 수직 접촉, 탄성 스토퍼와 표 형식 부품 힘을 비교할 수 있습니다. 자동 모션비는 예시 기하의 정적 소신호 값입니다.

다음 항목은 구현되어 있지 않습니다.

- 실제 하드포인트 입력과 공간 링크의 동시 구속을 푸는 3D 다물체 해석
- 차량 전체 피치·롤·요, 조향·토 변화, 부싱 유연성·마찰·백래시
- 타이어 횡력·종력·슬립과 회전 관성, 접촉 패치의 상세 모델
- 암·너클·홀더의 응력, 좌굴, 피로, 충돌과 유한 요소 해석
- 댐퍼 열·주파수·히스테리시스·캐비테이션, 실제 에어 시스템의 제어·유량

PNG·GLB는 화면과 자세의 전달 수단입니다. GLB 형상을 제조용 CAD나 구속이 검증된 기구로 취급하지 않습니다. 전체 스트로크의 기하와 하중 경로가 필요한 설계는 별도의 다물체·구조 해석으로 확인해야 합니다.

## 필요한 차량·시험 데이터

| 데이터 | 준비 내용 |
|---|---|
| 하드포인트·질량 | 좌표계·단위·정적 차고·장착점·질량 분배·비현가 질량·관성의 출처와 버전 |
| 모션비 | 실제 장착 상태의 휠 트래블 대비 축방향 스트로크; 현재 앱에서는 검증한 정적 수동값으로 사용 |
| 스프링 | 절대 압축량–축방향 힘, 자유 길이·프리로드·온도·반복성·측정 불확도 |
| 댐퍼 | 부호 있는 축속도–힘, 조절 단계·온도·시험 주파수·반복성; 축과 압축 부호 확인 |
| 타이어·스토퍼 | 수직 하중–변위, 압력·온도, 스토퍼의 작동 위치와 힘; 현재 단순 모델과 차이 기록 |
| 노면·운전 조건 | 실제 형상·장애물 위치·속도·질량·초기 상태와 입력 시각 |
| 센서 | 위치·축·샘플링·시각 동기·교정·영점·중력 처리·필터·단위와 원본 파일 |

부품 JSON에는 시험 출처와 식별 가능한 이름을 남깁니다. 예제 곡선은 실제 부품 측정값이 아닙니다. 시험 성적서와 원본 데이터는 별도 보관하며 앱 입력값의 유효성 검사가 측정 정확도를 보증하지는 않습니다.

## 수치 검증과 실차 타당성 검증

**수치 검증**은 의도한 방정식이 정확하게 구현되었는지 확인합니다. 정적 평형, 선형 폐형식 응답, 단위·부호, 접촉과 에너지 소산, 적분 간격 수렴, 독립 솔버와의 동일 모델 비교가 여기에 해당합니다. 단위·브라우저·제품·디자인·오프라인 자동 검사는 각자의 구현 범위를 확인합니다.

**실차 타당성 검증**은 목표 차량과 적용 조건에서 모델이 관측 응답을 충분히 설명하는지 확인합니다. 자동 검사 통과나 낮은 단일 RMSE로 대체할 수 없습니다. 다음 순서로 근거를 확보합니다.

1. 사용 목적과 적용 영역을 먼저 정합니다. 노면 종류·속도·질량·트래블·온도 및 비교 채널을 명시합니다.
2. 독립 솔버에 동일한 방정식·초기 평형·힘 곡선·접촉·스토퍼 조건을 입력합니다. 입력 차이와 수렴 오차를 분리합니다. RMSE·피크 오차·접촉 시각 등의 허용치는 평가 전에 프로젝트 책임자가 정합니다.
3. 같은 노면, 속도, 질량, 타이어 압력과 부품 설정으로 실험합니다. 센서를 교정하고 축·영점·중력·필터·시간 동기를 일치시킵니다.
4. 수동 시간 오프셋의 근거를 기록합니다. 앱은 `시뮬레이션 시간 = 실측 시간 + 오프셋`을 사용하며 자동 최적화하지 않습니다. 겹치는 관찰 구간과 표본 수를 함께 검토합니다.
5. 계수 조정에 사용하지 않은 별도 조건으로 확인합니다. 반복 시험과 불확도를 포함하고, 모델이 허용 오차를 만족하는 영역과 실패하는 영역을 문서화합니다.
6. 승인한 입력·모델·앱 버전을 고정합니다. 부품 또는 계산 방식이 바뀌면 영향 범위에 맞춰 다시 검증합니다.

곡선 외삽 비율은 데이터 범위를 벗어난 시간의 지표입니다. 허용 여부는 영향과 실측 근거로 판단해야 합니다. 댐핑 탐색의 접지 이탈 1% 필터와 기본 정착 임계값은 비교 도구의 규칙이며 차량 설계의 승인 기준이 아닙니다. 보편적인 오차 허용 수치를 임의로 제시하지 않습니다.

## 재현과 증거 보관

프로젝트 JSON은 설정·기록·스키마·모델 버전을 전달합니다. 실측 원본 CSV, 센서 교정 자료, 부품 성적서와 노면 입력의 증거는 별도로 함께 보관합니다. 같은 브라우저 주소의 IndexedDB는 작업 저장소이며 장기 보관의 유일한 수단으로 사용하지 않습니다.

HTML 실험 보고서와 실측 검증 JSON에는 조건·방법·제약을 남깁니다. 잔차는 승인된 센서와 동일한 시험 조건을 전제로 해석합니다. 보고서 출력은 데이터의 진실성이나 차량의 적합성을 인증하지 않습니다. 시험 통과 수와 실행 환경은 실제 QA 결과 파일에 근거하여 기록합니다.

## 상용 전달 전 결정 사항

| 항목 | 결정할 내용 |
|---|---|
| 적용 승인 | 설계 책임자, 사용 목적, 허용 오차, 모델 적용 범위와 승인 절차 |
| 지원 | 지원 OS·브라우저·GPU, 응답 시간, 결함 처리, 지원 기간과 버전 정책 |
| 데이터 | 백업·복구·스키마 이전, 고객 데이터의 보관·접근·이용 조건 |
| 배포 | 전달본 식별·무결성, HTTPS 루트 호스팅, PWA 캐시 업데이트와 롤백 |
| 라이선스·계약 | 앱 사용권, 재배포, 고객 부품 데이터의 권리, 보증·책임과 서비스 계약 |

앱의 상용 라이선스와 지원 계약은 별도 확정해야 합니다. 포함 라이브러리의 조건은 [제삼자 고지](THIRD-PARTY-NOTICES.md)를 확인하고 THREE 고지를 전달본에 유지합니다. 현재의 코드 완성과 수치 검사만으로 실차 설계 승인 또는 판매 가능한 지원 체계가 완성되었다고 판단하지 않습니다.

계산식의 세부 가정과 공식 참고 자료는 [모델 설명](model.md)에 있습니다.
