# 대시보드 구성 검증

> 이 문서는 이전 개발·배포 검증 기록입니다. 당시 요약과 수치는 역사 자료로 유지하며, 환경별 원본 QA 보고서·캡처는 공개 소스에서 제외했습니다. 현재 1.3.0 평가와 진행 상태는 [제품 평가 기록](consumer-release.md)을 확인하십시오.

2026-10-01, Suspension Lab **1.2.0 Engineering Preview**의 대시보드를 Chromium과 Playwright로 확인했다. 브라우저 61개와 전달본·오프라인 6개, 총 **67개 검사가 통과**했고 JavaScript·콘솔 오류는 0개였다. 모델은 `quarter-car-1.3`이다. 이번 변경은 정보 배치와 조작 흐름이며 물리 계산식은 변경하지 않았다. 이전 1.1.0의 수치·데이터 검사 52개 결과는 [제품 검증](product-validation.md)에 보관한다.

## 실제 배치와 데이터 확인

- 1440×1000에서 **scrollY=0**을 명시하고 첫 화면을 검사했다. 변경 전 계측 영역 끝은 페이지 y=1293px, 변경 후는 **y=982px**로 약 311px 올라와 3D 실험대와 네 계측 카드가 첫 화면에 함께 들어온다.
- 분석의 기본 배치는 변위·힘 두 열과 전체 폭 가속도 그래프다. 일반 데스크톱 그래프 높이는 300px, 작은 휴대전화는 270px다. 개별 집중 보기는 데스크톱에서 최대 530px, 휴대전화에서 330px다. 실제 숫자 눈금과 단위는 13px다.
- 설정 접기와 개요·세로·집중 보기 전환 전후의 시뮬레이션 상태, 샘플 이력, 시간 창, 추적 상태와 계열 선택을 비교했다. 표시 변경으로 값이나 표본을 지우지 않았다.
- 설정 패널 상태를 작업공간별로 보관하고 재접속 시 복원했다. 손상된 설정 저장값과 차단된 저장소에서도 기본 조작을 확인했다. 확대·Esc·복귀·탭 화살표·Space 입력을 검사했으며, 설정에 초점을 둔 채 화면이 작아져 패널이 접히면 설정 버튼으로 초점을 옮긴다.
- 상단 현재 설정을 45km/h로 변경한 뒤 저장 기록은 30km/h를 유지하는지 확인했다. 기록별 조건과 전체 시험 통계는 비교 영역에 따로 표시된다. 범위 문구는 실시간 표본, 그래프 구간, 기록 전체, 입력 CSV 비교를 구분한다.
- 다른 감쇠 값의 실제 2초 기록 두 개를 선택했다. 데스크톱에서 기록 목록과 비교 영역이 나란히 배치되고, 390px에서는 세로로 전환된다. 두 응답 경로와 기록 RMS가 실제 저장 이력·지표에 대응한다.
- 계수 모델, 부품 특성표 활성화와 외삽 발생을 구분했다. 좁은 댐퍼 표를 이용한 회귀시험에서 외삽 경고 문구와 색상이 실제로 바뀌었다. 이 표는 화면 검사에 쓰는 합성 입력이다.
- 1440×1000, 1280×900, 720×900, 390×844의 페이지 가로 넘침, 캔버스 크기와 눈금 경계를 확인했다. 네 검사 실행의 JavaScript·콘솔 오류는 0개였다.

## 전달본

ZIP을 작업 폴더 안에서 압축 해제하고 포함된 `serve.mjs`로 `http://127.0.0.1:5176`에서 실행했다. 완전한 정적 에셋 캐시, 네트워크 차단 후 새로고침·계산·기록 저장, 비교 커서 이탈 시 값 초기화, 390px 빈 특성표 안내문 경계와 배포 서버의 CSP·경로 제한을 확인했다. 이 실행에서 외부 네트워크 요청과 콘솔 오류는 0개였다. 검사 후 검증 문서·자료를 ZIP에 갱신했고 앱 번들은 동일하게 유지했다. ZIP 옆의 SHA-256 파일로 전달본 무결성을 확인할 수 있다.

## 재실행

소스 프로젝트에서 빌드와 검사를 실행한다.

```powershell
npm.cmd run build
npm.cmd run preview -- --port 5174 --strictPort
```

다른 터미널에서:

```powershell
$env:SUSPENSION_TEST_URL='http://127.0.0.1:5174'
$env:SUSPENSION_TEST_OUTPUT_SUFFIX='dashboard'
npm.cmd run test:dashboard
npm.cmd run test:product
npm.cmd run test:browser
npm.cmd run test:design
```

기록·입력·설치 데이터는 브라우저와 실행 주소에 종속된다. 전달본으로 시험을 옮길 때는 프로젝트 파일로 내보내고 가져온다. 이번 검사는 구현·표시·조작 검증이며 특정 차량에 대한 독립 실측 검증 결과를 추가하지 않는다.
