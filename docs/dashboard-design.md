# 대시보드 구성 변경

1.2.0에서는 사용자가 현재 조건과 결과를 오가며 확인하는 거리를 줄인다. 변경 전 1440×1000 화면에서 3D 캔버스는 600px 높이였고, 실시간 계측 카드 영역의 끝은 페이지 y=1293px였다. 수치 확인을 위해 아래로 스크롤해야 했다.

## 정보의 구분

상단 ‘현재 설정’은 다음 실험에 사용하는 실험대 설정이다. 저장한 기록을 비교할 때에도 과거 기록의 조건으로 바뀌지 않는다. 저장 기록별 조건은 비교 영역에서 확인한다.

실험대 계측 카드는 현재 시점의 값, 응답 분석의 그래프 아래 통계는 표시한 시간 구간의 표본, 실험 기록의 통계는 각 기록 전체 구간을 대상으로 한다. 상단 범위 표시는 이 차이를 알려주며, 스프링·댐퍼 특성표가 활성화됐는지도 표시한다.

설정 패널의 열림 상태는 작업공간별로 보관한다. 기본적으로 데스크톱 실험대에서 열고, 분석·기록·검증 및 작은 화면에서는 접는다. 사용자가 선택한 배치와 설정 패널 상태는 브라우저에 저장한다. 저장소가 차단되거나 값이 잘못되어도 기본 배치와 조작이 동작한다.

## 그래프 조작

- 개요: 변위·힘을 위쪽에 나란히 놓고 가속도를 아래 전체 폭에 표시한다. 작은 화면에서는 한 열로 배치한다.
- 세로: 모든 그래프에 전체 폭을 사용한다.
- 집중 보기: 한 그래프를 크게 보고 ‘전체 그래프’ 또는 Esc로 복귀한다. 다른 작업공간으로 이동하면 집중 보기는 해제된다.

표시 배치 변경은 시뮬레이션을 다시 계산하지 않으며, 이력·시간 창·계열 선택을 보존한다. 계산 정확도나 물리 해석 범위를 높이는 변경은 아니다. 화면 크기와 입력 동작의 확인 결과는 [대시보드 검증](dashboard-validation.md)에 기록한다.
