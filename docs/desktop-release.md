# Windows 설치·실행 안내

<!-- current-release-guide -->

대상은 **Suspension Lab 1.3.0**, 모델 `quarter-car-1.3`입니다. Windows x64 일반 체험용 기술 검증을 완료했습니다. 소스·독립 실행·오프라인·설치 파일 대조와 1.2.0에서의 실제 업데이트를 확인했습니다. 기술 검증과 유료 판매 개시는 별도이며, 제공 파일은 릴리스 페이지에서 확인합니다.

## 설치와 첫 실행

배포 위치는 [Releases](https://github.com/Ulsancl/suspension-simulator/releases)입니다. 실제 제공 파일은 해당 페이지에서 확인하며 `Suspension-Lab-Setup-1.3.0.exe`와 동명 `.sha256`을 함께 사용합니다.

1. 설치 파일을 실행하고 설치 위치를 선택합니다. 현재 Windows 사용자 계정에 설치하며 관리자 권한을 요구하지 않습니다.
2. 설치를 마친 뒤 바탕화면 또는 시작 메뉴의 **Suspension Lab** 아이콘을 클릭합니다.
3. 안내에서 **A/B 예시 실험 해보기**를 실행하거나 노면·속도·스프링·감쇠 조건을 직접 바꿉니다.

앱과 Electron 실행 환경을 함께 패키징하므로 설치된 앱에 Node.js나 별도 웹 서버가 필요하지 않습니다. 콘텐츠와 계산은 앱에 포함하며 3D 화면에는 WebGL 2를 사용할 수 있는 그래픽 환경이 필요합니다. 1.3.0 독립 실행본의 오프라인 첫 실행을 확인했습니다.

설치 폴더의 `resources/사용 안내.txt`에 조작법이 있습니다. `resources/docs`에는 모델·입력 형식·저장 복구·제품 평가 문서를 포함합니다.

## 조작과 첫 A/B 실험

| 작업 | 방법 |
| --- | --- |
| 재생·일시정지 | 화면 버튼 또는 Space |
| 실험 초기화 | R |
| 3D 크게 보기 | F |
| 앱 전체 화면 | F11 |
| 프로젝트 열기·저장 | 파일 메뉴 또는 Ctrl+O·Ctrl+S |
| 작업공간 이동 | 보기 메뉴 또는 화면 탭 |
| 사용 안내·저장 폴더 | 도움말 메뉴 |

**감쇠가 클수록 항상 좋을까요?** 예시는 사용자의 현재 설정을 유지하면서 기록 두 개를 만듭니다. 탄성 차체·더블 위시본·코일 스프링, 30 km/h, 높이 6 cm의 범프 한 번과 8초 시험을 사용하며 리바운드 감쇠만 A **900**, B **4,200 N·s/m**로 바꿉니다. 실제 차체 가속도 RMS·잔흔들림 정착 추정·접지 이탈 비율을 읽고 **두 기록 그래프 보기**로 비교합니다.

8초 안에 정착을 확인하지 못한 경우에는 그 사실을 표시합니다. 공간 부족이나 취소 시 기존 기록을 유지하며 두 예시 기록은 함께 보관합니다. 안내·취소·완료·파일 복원·재실행·보관 한도는 현재 브라우저 회귀에서 확인했습니다. 소스와 독립 실행 앱의 안내·결과 보관 확인도 통과했습니다.

CSV·HTML·PNG·GLB와 프로젝트 내보내기는 Windows 파일 대화상자로 처리하며 취소를 성공으로 표시하지 않습니다. 프로젝트 파일은 40 MiB 이하를 허용합니다. 지원하지 않거나 잘못된 파일을 열 때 현재 설정과 보관 기록을 유지합니다.

라이브 재생은 창을 숨기거나 최소화하면 잠시 멈춥니다. 표준 시험·감쇠 탐색과 파일 작업은 완료 후 종료하십시오. 계산 또는 파일 작업 중 창을 닫을 때는 진행 중인 작업을 안내합니다.

## 저장·이전 기록·복구

기본 저장 폴더는 `%APPDATA%\Suspension Lab`이며 **도움말 → 저장 폴더 열기**에서 확인합니다. 같은 앱 주소와 저장 폴더를 유지해 설정·프로젝트 이름·차량 이름과 보관한 기록을 복원합니다.

실시간 재생 이력과 보관한 시험 기록은 다릅니다. 필요한 조건으로 시험 기록을 만든 뒤 **프로젝트 파일 저장**으로 현재 설정과 기록을 `.suspension.json` 파일에 백업합니다. 원본 실측 CSV·센서 교정 자료·부품 시험 성적서는 프로젝트에 포함하지 않으므로 별도로 유지합니다.

지원하는 이전 모델 기록은 원래 샘플·지표·모델 버전을 유지한 **읽기 전용 기록**으로 엽니다. 현재 모델로 다시 계산해 과거 결과처럼 표시하지 않습니다. 현재 모델의 새 계산은 새 기록으로 만들며 이전 기록과 함께 비교·내보내기할 수 있습니다.

손상 원문과 지원하지 않는 미래 형식도 보존합니다. 원문 사본 저장이나 저장 공간 사용에 실패하면 메모리 보관과 파일 백업 안내를 표시합니다. 메모리 보관은 종료 후 유지되지 않으므로 프로젝트 파일을 저장하십시오. **원문 내려받기**와 **보관 기록 복구**의 차이는 [저장과 복구 안내](storage-recovery.md)에 있습니다.

웹 실행 주소의 저장소와 Windows 앱 저장소는 별도입니다. 기존 웹 주소에서 프로젝트 JSON을 내보내고 Windows 앱의 **프로젝트 열기**로 가져옵니다. 저장 복구가 필요한 경우 원문도 먼저 별도 파일로 보관하십시오.

## 업데이트·제거·파일 확인

자동 업데이트와 코드 서명 인증서 설정은 포함하지 않습니다. 새 버전으로 갱신할 때 프로젝트를 백업하고 앱을 종료한 뒤 새 설치 프로그램을 실행합니다. 앱 이름·주소·저장 폴더를 유지합니다.

Windows **설정 → 앱 → 설치된 앱 → Suspension Lab → 제거**로 앱을 제거합니다. 일반 제거는 사용자 데이터 폴더를 삭제하지 않습니다. 해당 폴더를 직접 삭제하면 설정과 보관 기록도 제거됩니다.

설치 파일 옆의 `Suspension-Lab-Setup-1.3.0.exe.sha256`은 전달 파일의 동일성 확인에 사용합니다. 해시는 게시자 서명을 대신하지 않습니다. 생성한 설치 파일의 실제 서명 상태는 `NotSigned`입니다. 파일 확인에는 동명 `.sha256`을 사용하며 이 문서에 해시·바이트 수를 고정하지 않습니다.

## 소스 실행·패키징

소스에는 Node.js **22.12 이상**과 npm이 필요합니다. CI는 Node.js **24.19.0**과 lockfile을 사용합니다. 의존성·Electron·패키징 도구를 처음 준비할 때는 인터넷 연결이 필요합니다.

```text
npm ci
npm run desktop
```

`desktop`은 웹 빌드를 준비한 뒤 앱 창을 실행합니다. Windows 설치 파일과 SHA-256은 다음 명령으로 만듭니다.

```text
npm run package:desktop
```

출력 파일은 `release/windows/Suspension-Lab-Setup-1.3.0.exe`와 같은 이름의 `.sha256` 파일입니다. 웹 ZIP은 `npm run build` 이후 `npm run package:release`로 별도 생성합니다.

```text
npm test
npm run build
npm run test:desktop
```

소스 앱 검사와 소스 없이 실행하는 배포 EXE 검사는 구분합니다. 전체 기준·환경·한계는 [제품 평가 기록](consumer-release.md)에 기록하며 원격 CI 성공은 이 로컬 평가에 포함하지 않으며 실제 실행 상태는 [Actions](https://github.com/Ulsancl/suspension-simulator/actions)에서 확인합니다.

## 이전 1.2.0 검증 이력

아래는 **1.2.0 Engineering Preview** 당시의 역사 기록입니다. 1.3.0의 결과나 설치 파일 해시로 사용하지 않습니다. 과거 비공개 배포 주소와 개인 경로·프로필을 포함하는 원본 QA 자료는 공개 문서에 포함하지 않습니다.

당시 NSIS 설치 종료 코드 0, 바탕화면·시작 메뉴 바로가기 생성, 인터넷 없이 최초 실행과 3D 렌더링을 확인했습니다. 설치본 검사는 재생·정지·작업공간·도움말·표준 시험, 프로젝트 저장·파일 교체·취소·불량 파일 거부, 키보드 대화상자, CSV·HTML·PNG·GLB 내보내기와 취소, 파일 복원 중 종료 취소, 완전 종료·재실행 후 설정·기록 복원을 포함했습니다.

재설치 검사는 작업 폴더의 별도 시험 프로필에서 전체 설정·기록 유지와 설치된 앱·최종 패키지의 동일성, 두 번째 실행 시 기존 창 활성화를 확인했습니다. 실제 기본 사용자 저장 폴더에서의 앱 실행도 확인했으나, 사용자 데이터가 들어 있는 기본 프로필의 업그레이드 검사는 해당 결과에 포함하지 않았습니다.

현재와 이전의 구현 검사는 특정 차량의 실측 타당성이나 부품 강도 승인을 의미하지 않습니다. [모델 설명](model.md), [고급 기능의 엔지니어링 적용 조건](engineering-release.md), [제삼자 고지](THIRD-PARTY-NOTICES.md)를 확인하십시오. 앱 자체의 기존 **UNLICENSED** 권리 유보 상태를 유지합니다.
