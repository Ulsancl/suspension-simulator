# 안전한 빌드와 검증 산출물

배포 도구는 입력 파일과 상위 폴더의 심볼릭 링크·정션·특수 파일을 거부합니다. 데스크톱 패키지는 검증된 소스와 운영 의존성을 새 비공개 임시 디렉터리로 복사한 다음 생성합니다. 설치 결과는 완성된 디렉터리 단위로 게시하고 체크섬은 임시 파일에서 원자적으로 교체합니다.

브라우저·데스크톱 테스트도 새 임시 디렉터리에 기록한 다음 종료 시 기존 output 경로로 결과를 게시합니다. 기존 결과 경로에 연결 파일이 있으면 다른 위치에 기록하지 않고 실패합니다. 빌드는 해당 사용자가 소유한 깨끗한 작업 공간에서 실행하세요. POSIX에서는 다른 사용자가 쓸 수 있는 산출물 부모 폴더도 거부합니다.

이 검증은 다른 사용자가 심어 둔 경로를 따라 비밀 파일을 포함하거나 외부 파일을 덮어쓰는 일을 막기 위한 것입니다. 검증되지 않은 소스 코드나 npm 실행 스크립트 자체를 격리하는 도구는 아닙니다.
