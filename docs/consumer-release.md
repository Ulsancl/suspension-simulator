# 일반 체험·실험용 제품 평가

대상 버전: **Suspension Lab 1.3.0**, 모델 `quarter-car-1.3`. 한 바퀴의 노면 응답을 관찰하고 같은 조건의 기록을 비교하는 Windows 앱을 평가한다. 특정 차량의 설계·정비·안전 승인이나 부품 강도 검증을 제품의 평가 범위로 삼지 않는다.

**1.3.0 일반 체험용 기술 평가 통과.** 안내를 따른 A/B 실험, 결과 비교·보관, 저장 복구와 화면 조작을 평가하고 웹·소스 데스크톱·독립 EXE·설치 파일 대조·실제 설치 및 업데이트 검사를 통과했다. 배포 위치는 [Releases](https://github.com/Ulsancl/suspension-simulator/releases)이며 설치 파일의 실제 제공 여부는 해당 페이지에서 확인한다. 기술 평가와 유료 판매 개시는 별도다.

## 처음 사용하는 사람의 체험

**감쇠가 클수록 항상 좋을까요?** 안내는 사용자의 현재 설정을 유지하면서 분리된 A/B 예시 두 개를 계산한다. 더블 위시본·코일·탄성 차체, 30 km/h, 높이 0.06 m의 범프 한 번과 8초 시험을 사용하고, 리바운드 감쇠만 900과 4,200 N·s/m로 바꾼다. 차체 가속도 RMS·정착 추정·접지 이탈 비율을 실제 결과에서 읽고 같은 시간축의 그래프로 비교한다.

정착을 기록 시간 안에 확인하지 못하면 이를 명시하며 0초 또는 정착 완료로 바꾸지 않는다. 두 기록을 함께 추가하고 보관 공간 부족·취소 시 기존 기록을 유지한다. 이전 실행의 예시 기록을 불러올 때는 저장된 결과를 보여 주며 자동으로 다시 계산하지 않는다. 안내·취소·완료·프로젝트 복원·재실행·보관 한도와 안내가 있는 첫 화면 배치를 브라우저 회귀 5개에서 확인했다. 소스·독립 실행 앱에서도 안내와 결과 보관의 연결을 확인했다.

수집한 JavaScript·페이지·콘솔 오류는 해당 검사에서 0이었다. 외부 콘텐츠 요청을 수집한 소스·독립 데스크톱 검사와 설치 실행 검사에서도 0이었다. 안내·최종 저장 검사는 실제 사용자 AppData를 수정하지 않았으며, 실제 설치 업데이트의 데이터 확인에는 이전 시험 프로필의 사본을 사용했다. 설정과 원래 기록을 유지했고, 설치된 실행 내용이 시험한 배포 내용과 같으며, 두 번째 실행이 기존 창 하나를 재사용하는 것을 확인했다. 바탕화면과 시작 메뉴 바로가기의 1.3.0 대상도 확인했다.

검사 PC의 GPU는 RTX 5080이다. 헤드리스 Chromium·ANGLE SwiftShader를 사용한 화면 검사는 구현·표시 회귀이며, 그 부하나 시간값을 실제 GPU FPS 또는 다른 컴퓨터의 성능 보장으로 사용하지 않는다. 1.3.0 실제 앱 대표 화면으로 갱신했다.

Windows 설치 프로그램과 동명 `.sha256` 파일을 생성했고 실제 서명 상태는 `NotSigned`였다. 설치 파일 확인에는 릴리스에서 함께 제공하는 SHA-256 파일을 사용한다. 문서 안에 설치 파일의 해시나 바이트 수를 고정하지 않는다. 문서·고지 갱신으로 재패키징할 때는 실행 내용의 동일성과 새 전달 파일을 다시 대조한다.

원격 CI 성공은 이 로컬 평가에 포함하지 않는다. 준비한 워크플로의 실제 실행 상태는 [Actions](https://github.com/Ulsancl/suspension-simulator/actions)에서 확인한다. 앞선 저장수정 단계의 단위 57개·저장 5개 이력과 현재 최종 단위 66개·최종 저장 5개를 구분한다. 저장 형식과 복구 의미는 [저장과 복구 안내](storage-recovery.md)에 있다.

과거 1.2.0의 설치·제품 검증은 [설치·배포 안내](desktop-release.md)의 이전 검증 이력 구간과 관련 문서에 보존한다. 과거 Engineering Preview 표기는 당시 고급 기능의 범위이며 1.3.0 소비자 평가를 실차 타당성 검증으로 대신하지 않는다.

## 제공 범위와 남는 제한

모델은 수직 단일 휠의 축약 해석이다. 표시 링크·스튜디오·GLB는 대표 형상이며 특정 차종의 하드포인트·부품 시험·검증용 실측 데이터나 제조 CAD를 제공하지 않는다. 기하에서 얻은 정적 모션비를 시험 중 일정하게 쓰는 가정 등은 [모델 설명](model.md)에 있다. 부품 곡선·CSV·선형 모드·오차 분석은 입력 조건과 단위를 확인해서 사용하는 고급 기능이다.

Windows x64와 WebGL 2를 지원하는 그래픽 환경을 대상으로 한다. 설치본은 실행 환경을 포함하며 첫 실행부터 오프라인으로 사용한다. 디지털 서명과 자동 업데이트는 없다. 프로젝트 파일과 원본 실측 CSV를 별도로 보관하고 새 설치 파일로 갱신한다.

일반 체험용 제품의 기술 평가와 유료 판매 개시는 별도 상태다. 가격·구매 경로·지원 기간·환불 조건을 이 기술 평가 문서가 정하지 않으며 판매 계약이나 차량 안전 승인을 제공하지 않는다. 앱 자체의 기존 `UNLICENSED` 권리 유보와 [외부 구성요소 고지](THIRD-PARTY-NOTICES.md)를 유지한다.

## 공개 자료

제품별 소스 저장소에는 코드·lockfile·검사·설명 문서와 자체 앱의 선별 대표 화면만 넣는다. 개인 경로·시험 프로필·원본 QA 로그가 들어 있는 `output/`, 의존성과 배포 출력은 제외한다. 설치 EXE와 동명 SHA-256 파일의 배포 위치는 [Releases](https://github.com/Ulsancl/suspension-simulator/releases)다. 실제 제공 파일과 원격 실행 상태는 해당 릴리스와 Actions 페이지에서 확인한다.
