# 디자인·응답 분석 검증

> 이 문서는 이전 개발·배포 검증 기록입니다. 당시 요약과 수치는 역사 자료로 유지하며, 환경별 원본 QA 보고서·캡처는 공개 소스에서 제외했습니다. 현재 1.3.0 평가와 진행 상태는 [제품 평가 기록](consumer-release.md)을 확인하십시오.

최신 1.2.0 대시보드의 변경과 회귀 검사 결과는 [대시보드 검증](dashboard-validation.md)에 별도로 기록했다. 아래 자료는 1.1.0 검증 이력이다.

2026-10-01 기준으로 1.1.0 Engineering Preview의 프로덕션 번들 `/assets/index-o0KzJyMT.js`를 `http://127.0.0.1:5174`에서 검사했다. 디자인·분석 기능 12개 검사가 모두 통과했으며 브라우저 실행 오류와 콘솔 오류는 없었다. 기존 기본 기능의 브라우저 회귀 검사 16개도 프로덕션 번들 `index-B6jKQ5H1.js`에서 통과했다. 제품 기능과 마지막 문구 수정의 검증 범위는 [제품 검증 결과](product-validation.md)에 구분해 기록했다.

## 확인한 동작

- 범프 입력을 2초 실행한 실제 기록에서 차체·휠·노면 변위, 접지력·스프링 힘, 차체·휠 가속도 7개 계열의 변화와 SVG 경로를 확인했다.
- 데스크톱의 그래프 높이는 320px, 모바일은 270px이며 숫자 눈금은 실제 SVG 크기에서 13px로 표시된다. 1440×1000, 720×900, 390×844 화면에서 가로 넘침을 확인하지 않았다.
- 포인터의 원시 SI 수치가 가장 가까운 기록 샘플과 일치하고 세 그래프의 커서가 같은 시점을 가리키는 것을 확인했다.
- 범례로 해당 곡선을 숨기고 다시 표시할 수 있다. 표시 시간 선택과 휠 확대·축소가 동작하며 그래프 위의 휠 조작은 페이지를 스크롤하지 않는다.
- 드래그로 이전 구간을 탐색해도 시뮬레이션 재생은 계속된다. 새 데이터가 추가되어도 탐색 위치가 유지되며 전체 구간 복귀를 누르면 현재 시점의 추적을 재개한다.
- 선택한 구간의 샘플에서 RMS, 절대 최대값, 압축·신장 스트로크, 최소·최대 접지력, 접지 이탈 비율을 독립적으로 다시 계산하여 표시된 12개 요약 수치와 비교했다.
- 고품질·표준 품질 선택이 실제 캔버스 크기 또는 그림자 설정을 바꾸는 것을 확인했다. 부품 진단과 스크린샷에서 위시본의 A암 2개, 멀티링크의 독립 로드 5개, 맥퍼슨의 하부 A암·텔레스코픽 스트럿을 구분했다.
- 에어 벨로즈와 일정 피치·가변 피치 코일의 차이를 직접 확인했다. 마지막 모바일 노면 라벨도 캔버스 안쪽에 모두 표시된다.
- CSV와 설정 JSON 저장·불러오기 동작은 그래프 변경 이후에도 유지된다.
- 검사는 실험대와 응답 분석 작업공간을 전환하는 현재 사용 흐름에 맞춰 실행했다. 긴 그래프 crop은 고정 탭 바만 캡처 스타일로 숨겼고 실제 전체 화면은 탭 바를 유지했다.

구간 요약은 현재 보이는 시간 범위의 **기록된 샘플**만 사용한다. RMS는 샘플 제곱의 평균에 제곱근을 취한 값이며 접지 이탈은 해당 샘플 수의 비율이다. 전체 실험 시간에 대한 누적 계측과 집계 범위가 다르므로 두 값이 항상 같을 필요는 없다. 시각적 상세화는 수직 동역학의 방정식이나 정밀도를 바꾸지 않는다. 모델의 해석 범위는 [모델 설명](model.md)에 정리되어 있다.
